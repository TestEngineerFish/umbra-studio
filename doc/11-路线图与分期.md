  `npm run ui` + 浏览器已经是完整可用的形态，每期都能真测。

## 二、架构演进：每一期加了什么

### 2.0 今天（M0 完成后的状态）

```
┌─ 界面（浏览器）: S1 索引 · S2 预览壳+节点属性面板 · S3 诊断 · S4 变更 · S5 设计系统
│      ↕ 本地 JSON API（/__ud/*，随机令牌 + Origin 校验）
├─ 本地静态服务（127.0.0.1，随机端口）
├─ 核心层: 写入口 / 校验 / 渲染体检 / 语义快照与 diff / 节点地址 / 属性级写入 / 回退
└─ MCP server（stdio，27 个工具）—— 外部模型客户端从这里接
```

入口两条：`npm run ui`（人）· MCP 注册（外部模型）。

### 2.1 M1 加：生命周期能力层

核心层里新增一组操作（项目 / 稿件的增删改移 + 引用图谱），
**同时**暴露成 MCP 工具与本地 API —— 模型和界面用同一套。
新增一屏 S8 项目设置。

⚠️ 关键前置：引用图谱。`dc-import` 按文件名解析（`01` H4），
不先解决它，改名 / 移动 / 删除每一条都在埋雷。

### 2.2 M2 加：AI 会话层（两条大脑通道）

```
S9 会话面板 ──→ 会话层 ──┬─ 通道 A: provider 适配器（OpenAI Chat Completions 形状）
                        │     DeepSeek 按量 / 智谱通用 API 按量 / 其他兼容端点
                        └─ 通道 B: 子进程 Claude Code（headless）
                              模型指向 GLM Coding Plan 的 Anthropic 端点
                              —— 这样订阅额度才是合规使用（依据见 01 §六）
```

两条通道对上层是同一个接口；界面上只是「用哪个大脑」。
通道 A 是底线能力，通道 B 是增益（它依赖两个外部产品的行为）。

**会话层调的是我们已有的 27 个工具**，落盘仍走唯一写入口（`01` H3）。

### 2.3 M3 加：外壳

Tauri 壳 + 菜单 / 最近项目 / 文件夹对话框；
现有 server 作为 sidecar 由壳启停，端口与令牌交接给前端。
**这一期不该改核心层** —— 如果发现要改，说明前面某处把浏览器形态写死了。

### 2.4 M4 / M5

M4 只加界面（S6 对比、组件 props 面板、多宽度、深浅色、缩略图）。
M5 是跨稿搜索、token 编辑、并发写保护、文档债。

## 三、每一期的「可测试」是什么意思

不是「跑起来没报错」，是**有一条能复述的读数**，并且沉到 `fixtures/`：

| 期 | 回归 | 判据 |
| --- | --- | --- |
| M0 | `npm run selftest` / `rendertest` | 基准精确匹配 · 界面稿零 error · 语料零误报 |
| M1 | `npm run lifecycletest`（新） | 脚本化走完建→改名→移动→删→恢复，每步后 `E_IMPORT_MISSING` 为 0 |
| M2 | `npm run agenttest`（新） | 固定提问对固定稿，**不判措辞**，只判三件：改动落点 / 四级分级 / 能否回退 |
| M3 | 手工一遍 | 干净机器上走完首次使用流程 |
| M4 | 渲染基准扩充 | 并排对比的高亮位置与 S4 的行号对得上 |
| M5 | 各自 | 见 `12` §六 |

**M2 的判据要特别说一句**：AI 的输出不可复现，所以回归**不能判它说了什么**。
判据只能落在可验证的三件事上。这一条是为了避免把回归写成一个永远在飘的测试。

### 4.1 Q2 的落地细节（核实过的，不是推断）

- **DeepSeek**：OpenAI 兼容 `https://api.deepseek.com`，另有 Anthropic 兼容
  `https://api.deepseek.com/anthropic`；支持 tools 与流式；按量计费。
  **模型名由用户在配置里填，不硬编码** —— 各家迭代很快，写死迟早过期。
- **智谱 GLM Coding Plan**：官方文档明写「仅限在官方支持的指定工具与产品环境中使用」，
  且「在除规定工具外调用 API，不可享用 Coding 套餐的额度」。
  官方支持的工具里包含 Claude Code / OpenCode / OpenClaw 等。
  → 自研客户端直连**用不到订阅额度**，所以订阅只能走通道 B。
- **智谱通用 API（按量）**：走通道 A，和 DeepSeek 同一个适配器。
